# Sales page blueprint ($10k/mois service business)

Source : transcript YouTube (website strategist). "Une seule sales page", testée, conversions 9% → 20%+.
Études citées : page bien conçue +200% conv. ; UX globale (vitesse, navigation, clarté, parcours) jusqu'à +400%.

But de la page : outil de vente focalisé qui transforme le trafic en clients/leads (vendre un service, booker consults/appels/rdv). Mêmes principes quel que soit le service, car la psychologie humaine est constante. Guide le visiteur dans son parcours d'achat.

---

## Navigation (top)
- Logo top-left, **bouton CTA top-right**, quelques liens à gauche du bouton.
- **Peu de liens** (Pricing, About, Services, FAQs) : minimiser les distractions, garder le focus sur le contenu.
- Respecter les **conventions de layout** (logo gauche / bouton droite). Inverser force le cerveau à réfléchir → attention détournée de la vente.
- Nav **sticky** : reste en haut au scroll, bouton toujours accessible.

## Hero section
3 choses avant le scroll : **quoi**, **comment ça améliore leur vie**, **quoi faire pour l'obtenir**.
- **Headline** : clair et direct (pas "cute/clever"). Le gros résultat obtenu en travaillant avec toi.
- **Sub-headline** : ce qu'est le service, pour qui, comment il est délivré (ramène la promesse sur terre).
  - Ex The Happy Sleeper : headline "sleeping through the night" → sub "via on-demand sleep classes".
- **CTA button** : visuellement saillant + langage action **à la 1re personne**.
  - "Book **my** free strategy session" pas "Book your...". Étude Unbounce : "my" vs "your" peut +90% CTR.
  - Dire ce qui se passe au clic (call ? proposal ?) → enlève le flou.
- + **Social proof** (logos B2B, nb d'avis 5★, stats de résultats).
- + **Image** : montrer le client idéal dans son **after state** (problème déjà résolu). Ex bébé qui dort paisiblement, pas le parent stressé. Pas toi/ton équipe ici. L'image dit "ça pourrait être toi".

## Problem section
- **Headline bold** qui capture le problème principal.
- **Bullet points** des symptômes spécifiques (bullets = 55% plus lues que des paragraphes).
  - Ex Friday Habits : "The health of your business is too important to neglect" + 4 bullets touchant vie pro ET perso.
- Pas pour culpabiliser : montrer que **tu comprends**. S'ils voient que tu reconnais leur galère, ils supposent que tu sais la régler.

## Solution section
- Te positionner comme le **guide** (le client reste le héros).
- Te présenter brièvement comme la solution : focus sur **comment tu aides**, pas qui tu es.
- Établir l'**autorité** (qualifs, expérience, awards) sans se vanter + **empathie** (histoire/expérience perso qui montre que tu comprends). Les deux.
- Explication claire de comment le service résout le problème (overview, pas tous les détails).
  - Ex Dr Sherry : qualifs + Ted Talk (autorité) + compréhension des challenges.
- **Première fois qu'on montre ton visage / ton équipe** (humanise). Sans personnes réelles, un site semble déconnecté voire louche.

## Benefits section
- Focus **résultats et outcomes**, pas features. Les gens achètent des versions meilleures d'eux-mêmes.
- Chaque benefit = **titre** (le résultat) + **description courte** (la feature qui le rend possible). Buy-in émotionnel + backup logique ("se sentir smart d'acheter").
- **Visuels** par benefit (icônes/photos/illustrations) : contenu avec images = +80% de chance d'être lu.
  - Ex Ollie : "happier healthier bestie", "wildly convenient". Critique : "wag-worthy recipes" = juste une feature ; préférer un benefit (longévité, meilleur lien avec le chien) expliqué par les recettes.

## Action plan section (souvent zappée = erreur)
- Répond à "comment ça marche ?" avant qu'ils demandent → enlève le mystère, rend le 1er pas moins effrayant.
- **3 étapes** (magic number, mémorable) :
  - Step 1 : lancer la machine (l'action = ex "Book a call").
  - Step 2 : aperçu de ce que travailler avec toi donne (big picture, pas de détails → éviter l'overwhelm).
  - Step 3 : pas vraiment une étape, c'est la **transformation / happily ever after**.
  - Ex Murphy Marketing : book strategy call → le travail se fait → tu récupères le livrable pour ton marketing.

## Testimonial section
- La preuve > les promesses. Vrais quotes axées **résultats/transformations**.
- Format idéal : "Before I was struggling with X, now after working with you I've achieved Y and feel Z" (mini-histoire où le prospect se reconnaît).
- Pour chaque : **pull-quote headline de 2-3 mots** (les gens lisent les titres, pas tout) + **photo** de la personne (crédibilité) + **graphique 5★** (compris au premier coup d'œil).
- **Varier** les angles : un sur les résultats, un sur la facilité de collaboration, un sur le ROI.
- **Vidéo** si possible (plus dur à faker, émotions/expressions vendent). Logos sites tiers (Google, Trustpilot, Yelp...) + nb d'avis + liens = confiance (perçus comme non biaisés).
- Si peu de testimonials : en obtenir devient une priorité (demander aux clients satisfaits).

## FAQ section
- Pas juste répondre : **casser les objections** avant qu'elles surgissent (argent, temps, "est-ce que ça marche").
- Transformer chaque grosse objection en question + réponse claire, rassurante mais honnête (pas de sugar-coating).
- **5-6 max** sur la sales page (ne pas overwhelmer). Double effet : clarifie + montre que tu comprends. Objectif final : "ils ont pensé à tout, je n'ai plus d'objection".

## Call to action (final)
- Option 1 : bouton CTA + headline forte (**exactement le même bouton que le hero** : même couleur, même message).
- Option 2 (préférée) : **booking tool embarqué** (ex Calendly) → supprime les allers-retours email, réduit la friction. Moins d'effort = plus de conversions.
- Headline de push final : "Ready to get started? / Ready to transform your business? Let's talk."

## À retenir pour You Alive
- Nav minimaliste + sticky, CTA top-right répété tel quel partout.
- Hero : headline = résultat, sub = comment, CTA 1re personne ("Réserver mon..."), image = after-state.
- Ordre : Problem (bullets) → Solution (guide + visage) → Benefits (outcomes + visuels) → Action plan 3 étapes → Testimonials variés → FAQ = anti-objections → CTA final (Calendly).
